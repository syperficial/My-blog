⚠️ 报错问题原因 ​

数据初始为 undefined，访问 goods.categories[0] 会抛出错误

✅ 两种推荐解决方案： ​

✅ 方法一：可选链运算符 ?.

vue
<el-breadcrumb-item :to="{ path: `/category/${goods.categories?.[1].id}` }">
  {{ goods.categories?.[1].name }}
</el-breadcrumb-item>

✅ 方法二：使用 v-if 判断数据是否存在

vue
<el-breadcrumb-item 
  v-if="goods.categories && goods.categories.length > 0"
  :to="{ path: `/category/${goods.categories[0].id}` }"
>
  {{ goods.categories[0].name }}
</el-breadcrumb-item>

💡 提示： 推荐使用 v-if 方式处理，因为其控制渲染行为更彻底，避免空节点。

🔥 热榜推荐功能（动态组件 + 接口适配） ​

🌐 接口说明

js
// 热榜商品接口封装
export function getHotGoods({ id, type, limit = 10 }) {
  return httpInstance.get('/goods/hot', {

⚙️ 实现步骤 ​

① 使用 Props 接收 hotType

js
const props = defineProps({
  hotType: {
    type: Number,
    default: 1 // 1: 24小时热榜
  }
})

② 定义热榜标题映射关系

js
const TYPEMAP = {
  1: '🔥 24小时热销榜',
  2: '📈 周热销榜',
  3: '🏆 总热销榜'

const title = computed(() => TYPEMAP[props.hotType])

🔍 图片放大镜功能实现 ​

✅ 第一步：定义当前激活图片下标

js
const activeIndex = ref(0)

const enterHandler = (i) => {
  activeIndex.value = i // 鼠标悬浮时切换主图
}

✅ 第二步：获取鼠标位置（使用 useMouseInElement）

js
const { elementX, elementY, isOutside } = useMouseInElement(hoverRef)

✅ 第三步：监听鼠标坐标，更新滑块位置 + 大图偏移

js
watch([elementX, elementY, isOutside], () => {
  if (isOutside.value) return

  // 横向控制滑块
  if (elementX.value > 100 && elementX.value < 300) {
    left.value = elementX.value - 100
  }

  // 纵向控制滑块
  if (elementY.value > 100 && elementY.value < 300) {
    top.value = elementY.value - 100
  }

  // 边界处理
  if (elementX.value > 300) left.value = 200
  if (elementX.value < 100) left.value = 0
  if (elementY.value > 300) top.value = 200
  if (elementY.value < 100) top.value = 0

  // 放大图偏移计算（2倍缩放）
  positionX.value = -left.value * 2
  positionY.value = -top.value * 2
})

✅ 第四步：使用 Props 传递图片列表

js
defineProps({
  imageList: {
    type: Array,
    default: () => []
  }
})

📌 父组件传递图片数据：
