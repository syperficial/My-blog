🔧 2. 使用 Git 管理项目 ​

默认创建项目没有 Git 版本控制，需手动初始化

bash
git init                    # 🧱 初始化本地仓库
git add .                   # ➕ 添加所有文件
git commit -m 'init'        # ✅ 首次提交
git branch -M main          # 🏷️ 将主分支重命名为 main
git checkout -b dev         # 🧪 创建并切换到 dev 分支
git remote add origin ...   # 🔗 绑定远程仓库地址
git push -u origin main     # 🚀 推送到远程 main 分支

🔑 如果是第一次提交，还需配置用户身份：

bash
git config --global user.name '你的用户名'
git config --global user.email '你的邮箱或 token'

🧭 常用 Git 命令备忘 ​

bash
git status     # 当前状态（是否有修改）
git branch     # 查看本地分支
git branch -a  # 查看所有分支（含远程）
