🎨 安装 Sass 与样式定制配置 ​

bash
pnpm add sass -D

✅ 加 -D 是因为这是一个开发依赖，仅在开发阶段使用。

⚙️ 第二步：配置 Vite 支持 SCSS ​

js
import vue from '@vitejs/plugin-vue'
import vueDevTools from 'vite-plugin-vue-devtools'
import AutoImport from 'unplugin-auto-import/vite'
import Components from 'unplugin-vue-components/vite'
import { ElementPlusResolver } from 'unplugin-vue-components/resolvers'

export default {
  plugins: [
    vue(),
    vueDevTools(),
    AutoImport({
      resolvers: [ElementPlusResolver()],
    }),
    Components({
      resolvers: [ElementPlusResolver({
        importStyle: 'sass' // 🧵 注意拼写是 sass（不是 sacc）
      })],
    }),
  ],

  css: {
    preprocessorOptions: {
      scss: {
        // 🎯 自动注入 SCSS 文件，全局生效
        additionalData: `@use "@/styles/element/index.scss" as *;`
      }
    }
  }
}

📌 @use 是 SCSS 推荐的模块导入语法，比 @import 更现代，支持命名空间与 tree-shaking。

🪡 SCSS 文件建议结构 ​

建议你的样式目录结构如下：

bash
📂 styles/
├─ element/
│  ├─ index.scss     # 🎨 ElementPlus 样式覆盖入口
│  └─ button.scss    # 示例：按钮样式重写
├─ base.scss         # 💡 公共基础样式（重置、变量）
├─ mixins.scss       # 🧬 混入函数
├─ variables.scss    # 🎨 全局颜色、字体变量

✅ 最终效果 ​

你就可以在项目里直接使用定制化样式，而不需要每个组件都手动引入：

vue
<template>
  <el-button type="primary">自定义样式按钮</el-button>
</template>
