📘 HTML 面试知识点整理 ​

🔗 src 与 href 的区别 ​

属性含义加载行为
src（source）表示资源地址会暂停文档解析，等待资源加载完成后再继续（如 <script>、<img>）
href（hyper reference）表示超链接地址不会阻塞页面解析，只是建立与外部资源的关系（如 <link>、<a>）

🆕 HTML5 新特性 ​

  • 语义化标签：<header>、<footer>、<article>、<section> 等，增强文档结构的可读性和可维护性。

  • 新增表单控件：

  • 输入类型：email、number、date、color 等。

  • 属性：placeholder、autofocus、required 等。

  • 媒体标签：<audio>、<video>，支持原生音视频播放。

  • 本地存储：

  • localStorage：本地长期存储，页面关闭后数据仍在。

  • sessionStorage：临时存储，关闭页面或浏览器后清空。

🧠 HTML 语义化的理解 ​

  • 根据内容语义选择合适的标签，使结构清晰、层次分明。
  • 有利于 SEO 搜索引擎优化。
  • 提高代码可读性，便于团队协作开发与维护。

📄 <!DOCTYPE> 的作用 ​

  • <!DOCTYPE html> 是文档类型声明，告诉浏览器以哪种文档标准解析页面。
  • HTML5 中采用统一声明方式，启用标准模式，避免浏览器进入怪异模式（quirks mode）。

🪟iframe 的优缺点 ​

<iframe> 通常用来加载外部链接，不会影响网页的内容加载。 优点：

  • 可嵌入第三方网页或内容。
  • 增强页面模块复用性。
  • 常用于广告、视频嵌入等场景。
  • 用来加载显示比较慢的内容，如广告，视频等。

缺点：

  • 加载的内容无法被浏览器引擎识别，对 SEO 不友好。
  • 会阻塞 onload 事件加载。
  • 会产生很多页面，不利于管理。

🖼️ Canvas 和 SVG 的区别 ​

  • canvas 画布是通过 JavaScript 来绘制 2D 图，是逐像素进行渲染的。
  • SVG 矢量图是基于 XML 描述的 2D 图形语言，每个元素都是可用的，可以为其添加事件。

🚩 script 中 defer 与 async 的区别 ​

属性加载执行多脚本顺序
async异步加载加载完立即执行无法保证顺序
defer异步加载文档解析完成后按顺序执行保证顺序执行

🔠 元素分类 ​

行内元素（inline）：
a, span, strong, img, input, select, label

块级元素（block）：
p, div, h1, h2, h3, ul, ol, li, dl, dt, dd 空（void）元素：
hr, br, img, input, link, meta
