📊 ECharts 图表搭建指南 ​

基于 Vue 3 + ECharts 的业务图表组件封装与使用，支持自适应、自更新和重渲染能力。

🚀 第一步：安装 ECharts ​

bash
npm install echarts --save

在需要的组件中按需引入：

js
import * as echarts from 'echarts'

🧱 第二步：封装 ECharts 功能模块 ​

我们将封装两个模块：

  • useBusinessChartData 📐：用于生成图表配置项（option）
  • BaseChart 📦：封装通用图表逻辑（初始化、响应式、自适应等）

📦 BaseChart 核心逻辑说明 ​

1️⃣ 组件状态定义 ​

js
const chartRef = ref(null)         // 图表容器 DOM 引用
let chartInstance = null           // ECharts 实例
let isInitialized = false          // 是否已经初始化

2️⃣ 判断 Option 是否有效 ​

js
function isValidOption(option) {
  return option && typeof option === 'object' && Object.keys(option).length > 0
}

3️⃣ 初始化图表函数 ​

js
const initChart = () => {
  if (!chartRef.value || isInitialized) return

  chartInstance = echarts.init(chartRef.value)
  chartInstance.setOption(props.option)

  // 监听窗口大小变化，自动适配
  window.addEventListener('resize', resizeChart)

  isInitialized = true
}

4️⃣ 响应式观察侧边栏折叠状态（兼容布局自适应） ​

js
watch(isCollapse, () => {
  setTimeout(() => {
    resizeChart()
  }, 300) // 延迟以等待 DOM 更新
})

5️⃣ 实时更新图表配置项 ​

js
watch(
  () => props.option,
  (newOption) => {
    if (!chartInstance || !isValidOption(newOption)) return

    const safeOption = JSON.parse(JSON.stringify(newOption))

    nextTick(() => {
      chartInstance.clear()
      chartInstance.setOption(safeOption, true)
    })
  },
  { deep: true, immediate: true }
)

6️⃣ 监听图表容器尺寸变化（使用 ResizeObserver） ​

js
onMounted(() => {
  nextTick(() => {
    initChart()
  })

  const resizeObserver = new ResizeObserver(() => {
    resizeChart()
  })
  if (chartRef.value) {
    resizeObserver.observe(chartRef.value)
  }

  onBeforeUnmount(() => {
    resizeObserver.disconnect()
  })
})

7️⃣ 销毁时清理实例 & 监听器 ​

js
onBeforeUnmount(() => {
  if (chartInstance) {
    chartInstance.dispose()
    chartInstance = null
  }
  window.removeEventListener('resize', resizeChart)
})

🎯 渲染容器：固定宽高是必须的！ ​

图表渲染容器必须提供有效尺寸，否则会无法显示！

html
<div ref="chartRef" style="width: 100%; height: 400px" />

✅ 总结功能点 ​

功能点实现方式
自动初始化onMounted + echarts.init()
响应式更新watch(props.option)
尺寸自适应window.resize + ResizeObserver
兼容侧边栏折叠watch(isCollapse)
销毁清理onBeforeUnmount
多图表复用封装组件 + 传入动态 option
