js
const form = reactive({
  name: '',

  description: '',
  imageUrl: '',
  createdAt: new Date(),
})

export function timer(isoString) {
  const date = new Date(isoString)
  const y = date.getFullYear()
  const m = String(date.getMonth() + 1).padStart(2, '0')
  const d = String(date.getDate()).padStart(2, '0')
  return `${y}-${m}-${d}`
}

📝 总结 ​

  • 模块分明：添加商品、类别管理、商品列表职责清晰，便于维护。
  • 模拟接口：json-server方便开发，方便切换真后端。
  • 图片限制：只支持 JPG，最大2MB，保证数据安全。
  • 数据拷贝：编辑用副本，避免污染原数据。
  • 分页简单：前端 slice 实现，适合小数据，后端分页更优。
  • 操作反馈：成功失败提示明确，提升用户体验。
  • 预留扩展：类别支持未来异步加载，方便升级。
