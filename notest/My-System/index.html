🚀 项目介绍 ​

该项目是一个基于 Vue 3 的个人后台管理系统 ,涵盖常见的登录注册、权限控制、数据管理等功能。 主要用于管理以下模块：

  • 🏪 门店信息管理
  • 🛍 商品管理
  • 🧱 商铺管理（店铺结构与信息）
  • 👥 员工管理
  • 🔐 权限控制与角色管理

🔧 本地运行方式 ​

bash
pnpm install      # 安装依赖
pnpm dev          # 本地运行
pnpm build        # 打包构建

🛠 技术栈一览 ​

技术用途说明
Vue 3核心框架
Element PlusUI 组件库
Vue Router前端路由系统
Pinia全局状态管理（代替 Vuex）
Axios网络请求封装
ECharts数据可视化图表
Sass样式预处理语言
Vite新一代前端构建工具
json-server本地模拟接口服务
