🧪 使用 json-server 模拟后端数据 ​

快速搭建一个本地假接口服务，适合前端开发时脱离后端环境独立调试。

🗂️ 第一步：创建 Mock 数据文件 ​

在项目根目录下新建一个 mock 文件夹，并创建一个 db.json 文件：

📁 项目根目录
├── 📁 mock
│   └── 📄 db.json

📦 第二步：全局安装 json-server ​

bash
npm install -g json-server

🚀 第三步：启动本地假接口服务 ​

在项目根目录运行命令：

bash
json-server --watch mock/db.json --port 3001

📌 支持的 RESTful 请求： ​

  • GET
  • GET
  • POST
  • PUT
  • PATCH
  • DELETE

❌ 不支持复杂的后端逻辑 ​

  • 比如：
  • 用户登录鉴权、Token 校验
  • 动态角色权限控制（RBAC）
  • 数据校验（form 校验、字段必填、格式校验等）
  • 联表查询、分页逻辑封装（只能模拟）
