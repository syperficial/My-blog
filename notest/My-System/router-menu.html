个人后台管理系统中的路由菜单动态渲染方案 ​

在个人后台管理系统中，侧边栏菜单的动态生成，是提升开发效率与维护便利性的关键步骤。
本文将介绍一种基于 路由配置 的动态菜单渲染思路，并通过 组合式函数 封装逻辑，实现解耦与复用。

📦 路由配置示例 ​

我们使用懒加载，并通过为路由添加自定义字段 isMenu: true，标记需要出现在菜单中的路由项。

js
// 一级路由配置
{
  path: '/',
  redirect: '/index',
  isMenu: true,
  component: () => import('@/views/Layout/index.vue'),
  meta: { title: '工作台' },
  children: [
    {
      path: '',
      name: 'Home',
      component: () => import('@/views/Home/index.vue'),
    }
  ]
},

// 二级路由配置
{
  path: '/goods',
  name: 'Goods',
  component: () => import('@/views/Layout/index.vue'),
  redirect: '/goods/add',
  meta: { title: '商品管理' },
  isMenu: true,
  children: [
    {
      path: 'add',
      name: 'GoodsAdd',
      component: () => import('@/views/goods/components/GoodsAdd.vue'),
      meta: { title: '添加商品' },
      isMenu: true,
    }
  ]
}

🧩组合式函数封装 ​

我们将菜单生成逻辑抽离为一个组合式函数 useMenu()，具备以下功能：

✅ 核心逻辑 ​

  • 使用filter筛选出带isMenu的路由，再根据路由配置生成菜单项。
  • 利用 map 映射成包含 path，name，title，icon 等属性菜单项
  • 拼接完整路径，避免路径重复斜杠
  • 递归处理子菜单
  • 对菜单进行排序：无子菜单的优先，有子菜单拍后
  • 计算属性 区分有无子菜单和无子菜单项 模板渲染

📄 useMenu 代码实现 ​

js

import { computed } from 'vue'

export function useMenu(routes) {
  const filterMenu = (routes, basePath = '') => {
    return routes
      .filter(route => route.isMenu)
      .map(route => {
        const fullPath = route.path.startsWith('/')
          ? route.path
          : `${basePath}/${route.path}`.replace(/\/+/g, '/')

        const menuItem = {
          path: fullPath,
          name: route.name,
          title: route.meta?.title || route.name,
          icon: route.meta?.icon || '',
        }

        if (route.children && route.children.length > 0) {
          const children = filterMenu(route.children, fullPath)
          if (children.length > 0) {
            menuItem.children = children
          }
        }

        return menuItem
      })
  }

  const rawMenu = computed(() => filterMenu(routes))

  const menuItems = computed(() => {
    return [...rawMenu.value].sort((a, b) => {
      const aIsSingle = !a.children || a.children.length === 0
      const bIsSingle = !b.children || b.children.length === 0
      return aIsSingle === bIsSingle ? 0 : aIsSingle ? -1 : 1
    })
  })

  const haveChildren = computed(() =>
    menuItems.value.filter(item => item.children && item.children.length > 0)
  )

  const noChildren = computed(() =>
    menuItems.value.filter(item => !item.children || item.children.length === 0)
  )

  return { menuItems, haveChildren, noChildren }
}

💡 页面渲染示例（Element Plus） ​

结合 el-menu 组件，通过 haveChildren 和 noChildren 两个菜单分类，实现动态渲染。

vue
<template>
  <el-menu
    :default-active="route.path"
    :collapse="isCollapse"
    @open="handleOpen"
    @close="handleClose"
    @select="handleMenuSelect"
  >
    <!-- 无子菜单单项 -->
    <el-menu-item
      v-for="item in noChildren"
      :key="item.path"
      :index="item.path"
    >
      <el-icon><icon-menu /></el-icon>
      <template #title>{{ item.title }}</template>
    </el-menu-item>

    <!-- 有子菜单项 -->
    <el-sub-menu
      v-for="item in haveChildren"
      :key="item.path"
      :index="item.path"
    >
      <template #title>
        <el-icon><location /></el-icon>
        <span>{{ item.title }}</span>
      </template>
      <el-menu-item-group>
        <el-menu-item
          v-for="sub in item.children"
          :key="sub.path"
          :index="sub.path"
        >
          {{ sub.title }}
        </el-menu-item>
      </el-menu-item-group>
    </el-sub-menu>
  </el-menu>
</template>

🧾总结 ​

通过组合式函数 useMenu() 搭配计算属性和路由配置，可以实现一套 可维护、可扩展、动态驱动 的后台菜单渲染逻辑。该方案具有：

  • 📚 数据来源统一（基于路由配置）
  • ♻️ 解耦逻辑（封装组合式函数）
  • 🔁 自动响应（依赖 computed）
