📚 侧边栏展开/折叠功能说明 ​

使用 Pinia 状态管理实现了一个轻量的侧边栏折叠切换功能。

🏗️ 状态管理 - stores/Sidebar.js ​

使用组合式 API + Pinia 封装 sidebar 状态逻辑：

js
// stores/Sidebar.ts
import { defineStore } from 'pinia'
import { ref } from 'vue'

export const useSidebarStore = defineStore('sidebar', () => {
  // 📦 折叠状态：true 表示折叠，false 表示展开
  const isCollapse = ref(true)

  // 🔁 切换折叠状态的方法
  const toggleCollapse = () => {
    isCollapse.value = !isCollapse.value
  }

  return {
    isCollapse,
    toggleCollapse
  }
})

🧩 页面组件使用说明 ​

📌 LayoutNav.vue ​

在侧边导航组件中使用 Pinia 的状态：

js
<script setup>
import { useSidebarStore } from '@/stores/Sidebar'
import { storeToRefs } from 'pinia'

// 初始化 store
const sidebarStore = useSidebarStore()
// 解构响应式状态
const { isCollapse } = storeToRefs(sidebarStore)
// 引用方法
const { toggleCollapse } = sidebarStore

</script>

可以根据 isCollapse 控制 <el-menu :collapse="isCollapse"> 的展开折叠状态。

🧭 LayoutHeader.vue 中的切换图标按钮 ​

顶部菜单点击图标切换状态：

js
<script setup>
import { useSidebarStore } from '@/stores/Sidebar'
import { storeToRefs } from 'pinia'

// 引入图标资源
import OpenMenu from '@/assets/icons/OpenMenu.png?url'
import CloseMenu from '@/assets/icons/CloseMenu.png?url'

// 状态管理
const sidebarStore = useSidebarStore()
const { isCollapse } = storeToRefs(sidebarStore)
const { toggleCollapse } = sidebarStore
</script>
vue
<template>
  <div class="collapse-trigger" @click="toggleCollapse">
    <img :src="isCollapse ? OpenMenu : CloseMenu" alt="切换侧边栏" />
  </div>
</template>

🎨 示例效果 ​

  • ✅ 默认折叠侧边栏
  • ✅ 点击图标展开
  • ✅ 再次点击折叠
  • ✅ 所有组件响应式联动同步状态

📌 小结 ​

功能点实现方式
状态管理Pinia + ref
状态共享storeToRefs 解构响应式状态
图标动态切换:src="isCollapse ? A : B"
